## Chat

- **Enter** sends, **Shift+Enter** inserts a newline, **Esc** stops the current turn.
- Type **/** for Cursor commands and **@** to mention a file.
- Use **Add Selection to Cursor** (editor context menu) to include code.
- Permission prompts appear inline on the tool card: **Allow**, **Always allow** or **Reject**. Nothing runs without your say-so.
- The history icon lists previous sessions for this folder; the last one is resumed automatically.
