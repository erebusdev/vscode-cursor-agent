# Changelog

## 0.1.0

Initial release.

- Chat sidebar (and editor panel) for the Cursor Agent CLI over ACP.
- Streaming transcript with thoughts, tool cards, live output, inline diffs
  that open in the VS Code diff editor, task/todo lists, questions and plan
  proposals.
- Explicit permission prompts with keyboard shortcuts and notifications.
- Agent / Ask / Plan modes, model picker with per-model options, slash
  commands, @-file mentions, selection and image attachments.
- Session history, resume with replayed history, reconnect after process exit.
- In-app settings panel with executable probe, plus VS Code settings and a
  getting-started walkthrough.
- Usage panel reading Cursor's plan usage for the logged-in CLI account.
- Remote SSH support (runs on the workspace extension host).
